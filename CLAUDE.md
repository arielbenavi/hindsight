# hindsight

iOS app that turns a user's saved Instagram/Facebook posts into something usable. See [README.md](README.md) for product direction and repo layout.

- `ios/`: the iOS app. All new app work goes here.
- `data/`: seed export in the Muse `.md` format the app ingests.
- `web/`: **deprecated** web prototype. Reference only; don't extend it.

## iOS: XcodeGen is required

The Xcode project is generated by **XcodeGen** from `ios/project.yml`. `ios/Hindsight.xcodeproj` is gitignored and must never be committed. Details: [ios/README.md](ios/README.md).

- Before building, or after `project.yml` changes: `cd ios && xcodegen`. If `xcodegen` isn't installed, `brew install xcodegen`.
- New source files: create them under `ios/Hindsight/` (tests under `ios/HindsightTests/`). They're picked up automatically; don't edit `project.yml` for this.
- Targets, build settings, capabilities, bundle IDs, Info.plist keys, dependencies: edit `ios/project.yml`, then rerun `xcodegen`. Never change these in the generated `.xcodeproj`, because regeneration discards them.
- Build/test: `xcodebuild test -project ios/Hindsight.xcodeproj -scheme Hindsight -destination 'platform=iOS Simulator,name=iPhone 17'`
